```text

sha256=4a9cf7bd4885f3a97512fc94449bda18734ef6ee66a9b11ca3b2c52f4bef49f9
```

## 与 2026-08-18 调试记录的关系

2026-08-18 的历史调试记录证明在当时接线、机构状态和三参数 SDK 路径下，操作员曾获得特定
行程、瓶夹持和保护电流观察。它不能直接放行本次两参数帧路径，原因是：

1. 历史调用显式携带 `gripper_type=1`，本次明确禁止 type 扩展；
2. 历史“持续 moving/持续施力”是功能观察，不是独立测力、稳定性或 STOP 证据；
3. 本次新增“无位置变化但异响、触碰小幅抖动”反例，推翻了直接继承稳定保持假设；
4. 当前 `0x67/01` 响应语义、位置环死区、保护电流实际值、编码器反馈和机械临界点没有同步证据。

因此旧参数只能保留为历史条件证据，不能叫当前两参数路径的“已经验收配置”。

## 可能原因（未归因）

- 位置环在目标附近受齿轮回差/触碰扰动后 hunting；
- 当前保持/保护电流过高或与两参数路径的控制模式不匹配；
- 编码器死区、零点或反馈量化使 `16 -> 17` 落在不可观察区；
- 新连杆机构处于过中心、弹性预载或高摩擦临界区；
- `0x67/01` 的固件语义不是项目当前假定的“位置写成功”；
- 供电、接地、线缆或控制器状态在扰动下不稳定。

现有证据不能在这些原因中唯一选择，禁止以重复动作排查。
