# myCobot 280 M5 + 原厂 AG + 末端相机单瓶抓取实验运行单

日期：2026-08-20
当前状态：`OFFLINE_ONLY / REAL_EXECUTION_BLOCKED`

## 1. 本运行单的边界

本单用于未来一次严格分阶段的单物体实验：myCobot 280 M5、原厂 AG 自适应夹爪、侧上方
eye-in-hand 相机和一只固定摆放的空矿泉水瓶。本轮只编写、审查和测试运行单；没有访问 SSH、
ROS graph、串口或相机设备，没有连接、上电、使能或动作。

“训练”只允许对已记录图像做离线标注、误差统计和参数拟合。运动期间禁止在线学习、随机探索、
自动试错或由模型直接输出执行器命令。

机器可读 authority：`ag_eye_in_hand_single_bottle_experiment_policy.json`。人工记录不得覆盖其中
任何 fail-closed 条件。

## 2. 官方 AG 两参数候选协议

唯一候选位置写接口为：

```text
set_gripper_value(value, speed)
FE FE 04 67 VV SS FA
```

候选只读查询为零 payload：

```text
get_gripper_value()  -> FE FE 02 65 FA
is_gripper_moving()  -> FE FE 02 69 FA
```

这些帧来自 AG 产品/通信资料，只是本机固件重新绑定前的候选，不构成现场授权。明确禁止：

- 给 `set_gripper_value` 增加第三个 type 参数；
- 给 `get_gripper_value` 增加 type 参数；
- 发送 `FE FE 05 67 VV SS TT FA` 或 `FE FE 03 65 TT FA`；
- 自动探测帧变体、失败后回退扩展帧或用动作试错；
- 把 SDK 返回 `None` 当成 ACK；
- 把串口 `close()` 当成 STOP/去能；
- 在本实验中写保护电流、力矩、归零、校准或 `init` 命令。

2026-08-18 的第三参数事件及 `25 -> 26` 后反馈 `105/moving=1` 只作为事故证据，旧参数、零点、
行程和“持续施力成功”均不得继承到本运行单。

## 3. 末端相机身份与 D405 侧上方静态方案

项目曾只读识别到 JoyandAI `JYU2C-2083` UVC 相机；它不是 D405 身份证据。本运行单按用户指定
的 Intel RealSense D405 侧上方安装做候选机械方案，但在铭牌、USB 身份和内参绑定前保持
`REQUIRED_NOT_VERIFIED`，两者不得混称。

推荐拓扑是“侧上方、指尖平面后方、朝抓取中心内倾”：

1. 相机本体、镜头保护件、连接器和线缆都加入末端碰撞模型；不得只建一个无厚度光学帧。
2. 相机及紧固件不得进入双指从全开到候选瓶宽的扫掠体，也不得越过最前指尖碰撞平面。
3. 光轴必须覆盖预抓取、接近、接触三个阶段的抓取中心；具体平移、四元数和视场边界必须由
   CAD/实测给出，禁止使用模板数值。
4. 生成至少三类 self-mask：机械臂链节、夹爪全开/候选瓶宽/持瓶；mask 以像素和相机内参版本
   绑定，不能靠字符串改 frame。
5. 连接器后方保留厂商最小弯曲半径；线缆在腕部设置两点应力释放和服务环。对腕部允许的
   roll/pitch/yaw 极限做扫掠包络，禁止线缆擦碰连杆、夹爪或瓶子。
6. 相机、支架、紧固件和线缆的总质量/质心必须重新进入 myCobot payload、惯量和碰撞复核。
7. 静态 CAD 必测姿态：夹爪全开、候选瓶宽、持瓶、预抓取、抓取、抬升及腕部姿态极限。

静态方案的输出必须包含：受控 CAD revision、相机外形/孔位来源、安装变换、线缆扫掠体、
各姿态最小间隙、视锥与瓶体交集、self-mask、质量/质心，以及评审人签名。任一缺失即不能上机。

## 4. “机械臂无遮挡”假设失效后的 eye-in-hand 流程

原机身 RGB-D 相机只负责给出粗候选；机械臂进入画面后，其结果允许被遮挡，不能继续作为唯一
抓取 authority。每次机械臂增量后必须先静止，再由末端相机获取新鲜帧并重新识别同一只瓶子，
计算相对位姿和碰撞间隙。任何一步看不见、看见多个瓶子、身份跳变、帧过期或 mask 外遮挡，
都必须停在当前位置并进入物理断能，不得盲走下一段。

运行时始终遵守：一次只允许一个动作；动作完成并提交新观测前不能排队下一动作。不得从粗相机
坐标直接执行完整抓取，也不得在末端相机丢失后回退开环轨迹。

## 5. 现场逐步运行卡（未来使用，本轮禁止执行）

| 步骤 | 动作 | 必须观察 | 立即停止条件 | 人工断能职责 |
| --- | --- | --- | --- | --- |
| S00 | 无 | arm/AG/camera/firmware/policy/source 精确身份与 hash | 缺失、漂移、自报或不一致 | 全部执行器保持物理隔离 |
| S01 | 断能安装 | 相机、连接器、服务环、两点应力释放纳入包络，且不进入指爪扫掠体 | 松动、擦碰、弯曲半径未知、质心未复核 | 安全观察员掌握断能装置 |
| S02 | 无 | 底盘机械锁止并断能，扫掠区无人，仅一只空瓶固定 | 底盘可滚、人员/第二物体入区、瓶位不固定 | 指定观察员在断能装置旁 |
| S03 | 相机静止观察 | 末端新鲜帧、内参、frame identity、单瓶和夹爪可见 | 零/多瓶、流冻结、曝光失败、自遮挡未解、标定缺失 | 执行器继续物理隔离 |
| S04 | 只读 admission | 唯一 transport owner、可信静止、零 payload 查询帧 | type 扩展、非法反馈、moving、超时、health/identity drift | 只读不等于 STOP；随时人工断能 |
| S05 | 单次张开 | 动作级授权后只发一次两参数帧；方向、行程和新图像符合预期 | 方向/行程异常、持续运动、热/响/电流异常、相机或线缆移位 | 首次异常立即物理断能，不反向重试 |
| S06 | 单次预抓取 | 低速到受控 named pose；新帧重获同一瓶，净空为正 | 目标出 ROI、遮挡未解、轨迹偏离、视频冻结、间隙未知 | 首次异常物理断能 |
| S07 | 单步接近 | 每个小步单独授权；静止后重算相对位姿/净空 | 相对运动不单调、身份跳变、mask 外遮挡、地面/指尖净空丢失 | 同时只能有一个未完成增量 |
| S08 | 单次夹空瓶 | 只发一次两参数 close；图像和人工确认居中接触 | 偏夹、瓶身变形/滑动、超程、热/响/电流异常、扩展帧 | 人工断能为异常主路径，不发第二次 close |
| S09 | 有界静止 dwell | 图像、瓶位、工具位、反馈、温度和人工观察连续记录 | 滑动、变形、温升、transport/identity/staleness/motion uncertainty | 任一不确定锁存 physical isolation required |
| S10 | 单次释放并结束 | 瓶子有支撑，释放方向/净空已复核，最终能量状态可证明 | 瓶子悬空、方向不明、相机过期、状态不可信 | 以物理隔离结束；close 连接不是去能 |

S05-S10 每一步都必须有新的动作级明确授权；上一阶段通过不能自动授权下一阶段。首次异常后禁止
自动重试、反向恢复、归零或重新标定。
