# touch-only 机械臂几何现场测量表

状态：**未测量、未复核、禁止真实机械臂动作**。

用途：记录 myCobot 280 M5 在 LIMO 上的安装外参、软触碰头 TCP 和静态碰撞包络。本文档
只用于人工测量与复核，不启动机械臂，不调用 `release_all_servos()`，不发送关节、坐标、
夹爪或底盘命令，也不代表真实 touch-only 已获授权。

当前执行语义仍是 dry-run。没有力/触觉传感器时，后续即使完成动作验收，也只能报告
“到达计划触碰位姿”，不能声称已经检测到接触力。

## 7. 复核标准

- [ ] 三次平移测量最大差不超过 5 mm；超出则重新测量或改用安装板图纸/治具。
- [ ] 三次旋转测量最大差不超过 1°；超出则重新确认轴向与安装面。
- [ ] 使用右手坐标系复核正负号，至少由第二人独立检查一次。
- [ ] 所有单位已统一为米和弧度后再进入配置；不得混用 mm、度。
- [ ] 没有把空白或全零占位值标记为“已测量”。
- [ ] `touch_tcp` 与已断开夹爪的 TCP 明确区分。
- [ ] 碰撞包络包含线缆、接头和软触碰头压缩前的最大外形。
