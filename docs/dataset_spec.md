# LIMO Cleanup 首版目标检测数据集规范

更新时间：2026-08-05
状态：首版草案，实物到场后开始采集。

## 1. 目标

为首版 MVP 建立可复现的数据集：在空旷、平整、光照稳定的实验场地识别 2～3 类外观差异明显的垃圾，输出带置信度的检测框，供三维定位与抓取使用。

数据集与标注文件不进入 Git 仓库（`.gitignore` 已包含 `datasets/` 与 `models/`）。

## 4. 采集规范

采集时使用样机相机的实际安装高度与俯仰角，不要用手持高角度俯拍充数，避免训练数据与线上视角不一致。

每个实物按以下组合采集：

- 距离：0.3 / 0.6 / 1.0 / 1.5 m，覆盖抓取工作区到搜索距离。
- 水平角度：0° / 45° / 90° / 135° / 180°，物体绕自身竖直轴旋转。
- 姿态：正立为主，每类至少 20% 侧倒或平躺。
- 光照：正常室内光、偏暗、侧逆光，三种都要有。
- 背景：纯色地面为主，至少 20% 杂乱背景。
- 遮挡：无遮挡为主，每类至少 10% 部分遮挡（不超过 50%）。
- 多目标：至少 10% 画面包含 2 个以上目标或负样本干扰物。

数量目标（可按实际调整，拆分比例不变）：

| 类别 | 训练集 | 验证集 | 测试集 |
| --- | --- | --- | --- |
| plastic_bottle | ≥200 | ≥40 | ≥40 |
| can | ≥200 | ≥40 | ≥40 |
| paper_box | ≥200 | ≥40 | ≥40 |
| 负样本（空场景 / 其他物体） | ≥60 | ≥15 | ≥15 |

拆分规则：按实物实例拆分，同一个实物不得同时出现在训练集和测试集，防止模型“背答案”。

## 5. 标注格式

采用 YOLO 格式，每张图片对应一个同名 `.txt`：

```text
<class_id> <x_center> <y_center> <width> <height>   （均为 0～1 归一化）
```

- 标注框贴合物体外轮廓，不包含大段背景。
- 首版全部标注 100% 人工复核。
- 深度图与 RGB 图同步保存，文件名仅后缀不同，供三维定位只读验证使用。

## 6. 数据质量检查

- 图像模糊、严重过曝或欠曝的照片剔除重拍。
- 每批采集后抽查至少 10% 的标注质量。
- 训练前统计各类别标注框数量与长宽比分布，发现失衡回到采集规范补拍。

## 7. 验收指标与误检处理原则

- 检测置信度阈值与线上一致：`detection_gate.min_confidence = 0.5`。
- 首版目标：测试集召回率 ≥ 90%，背景误检 ≤ 1 处 / 10 帧。
- 线上策略：低置信度检测由质量门直接拒绝；后续真实感知节点再加入连续多帧一致才确认的机制（首版 N=3）。
- 误检成本高于漏检：宁可多搜索一轮，不可抓向错误位置。
