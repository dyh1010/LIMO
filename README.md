# LIMO AI Scout

ROS1/Noetic-first mobile manipulation research workspace for LIMO Pro,
DaBai RGB-D perception, voice dialogue, myCobot 280 M5 and a reviewed gripper.

Current status: **development / field delivery blocked**. Offline, pure-fake,
private-graph or read-only evidence must not be interpreted as authorization for
robot motion. Software STOP does not replace the physical emergency stop or
power isolation.
